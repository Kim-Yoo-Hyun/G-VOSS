Last updated: 2026-07-29 KST

This directory owns the active RelCompat3D manuscript, technical supplement,
reproducibility checklist, figures, bibliography, reviewer assessment, and
release-facing paper documentation.

## Current Identity

- Title: **RelCompat3D: Re-Ranking 3D Scene Graph Relations with Geometric
  Evidence**
- Venue: AAAI-27 Main Technical Track
- Method: predicate--geometry compatibility for family-aware re-ranking of
  fixed 3D scene graph relation predictions
- Variants: RelCompat3D-Linear and RelCompat3D-MLP
- Scope: re-rank proximity and vertical order while retaining support/contact
  in source order

## Terminology

- **validation split**: the official dataset partition;
- **validation scenes**: the evaluated reconstructed scenes;
- **shared**: the predictors use the same split, contexts, relation scope,
  metrics, and \(K\) values;
- **verifier-derived Violation**: the rule-based evaluation metric, not
  independently annotated physical validity.

## Build

From the repository root:

```bash
docker build -f paper/aaai/Dockerfile.tex \
  -t relcompat3d-aaai27-tex:20260712 paper/aaai

for stem in main supplement reproducibility_checklist_main; do
  docker run --rm -v "$PWD/paper:/work" -w /work/aaai \
    relcompat3d-aaai27-tex:20260712 \
    latexmk -pdf -interaction=nonstopmode -halt-on-error "${stem}.tex"
done
```

Canonical outputs are `aaai/main_aaai27.pdf`,
`aaai/supplement_aaai27.pdf`, and
`aaai/reproducibility_checklist_aaai27.pdf`. Page counts and hashes are updated
after the clean build in `reproducibility.md`.

Current page counts are 9/10/2. The main technical content ends on page 7 and
pages 8--9 contain references only. The current review upload uses the
canonical Technical Supplement PDF directly rather than a Code and Data
release bundle.

## Submission Upload Scope

- The main paper is already submitted and is frozen. Do not edit its section
  sources or rebuild its canonical PDF.
- Upload `aaai/supplement_aaai27.pdf` as the Technical Supplement.
- Do not upload a Media Supplement.
- Do not upload the staged Code and Data Supplement during review. The
  RelCompat3D implementation and machine-readable results are an internal
  post-acceptance release task and a post-publication checklist commitment,
  subject to third-party data and checkpoint terms.
