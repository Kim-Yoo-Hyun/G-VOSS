\title{Beyond Semantic Confidence: Relation-Consistent Geometric Re-ranking for 3D Scene Graphs}

\author{Anonymous Submission}
\affiliations{}

\begin{abstract}
    3D scene graph predictors can assign high scores to predicates that are inconsistent with the reconstructed geometry of the corresponding ordered subject--object pair. We formulate predicate–geometry compatibility for fixed relation predictions and introduce RelCompat3D, 
    a re-ranking framework. RelCompat3D preserves each ordered-pair identity of each candidate and estimates compatibility from predicate semantics and predicate-independent pair measurements without using the source relation score. Family-specific linear heads and a shared nonlinear estimator are trained with linked positive--counterfactual pairs. Transformation averaging enforces equal compatibility under the defined relation-preserving endpoint/predicate transformations. RelCompat3D combines compatibility with the source relation score to re-rank proximity and vertical-order candidates while retaining support/contact candidates in source order. We evaluate exact-match Recall@$K$ and verifier-derived Violation@$K$ for VL-SAT, Open3DSG, and SGFN on a shared 3DSSG target. Across all reported predictor–$K$ settings, both variants yield Recall point estimates no lower and Violation point estimates no higher than the corresponding source rankings. The largest changes occur on Open3DSG. Matched fusion baselines and controls show predictor- and family-dependent trade-offs. A point- and mesh-based audit supports the direction of the changes using alternative geometric measurements.
\end{abstract}

\section{Introduction}
3D scene graphs represent reconstructed scenes as structured objects and relations, supporting spatial reasoning, embodied AI, scene alignment, visual grounding, and downstream decision making \cite{armeni20193d,wald2020learning,sarkar2023sgaligner,xie2024sg,liu2026view}. A predicted relation must describe the corresponding ordered subject--object pair in 3D, not merely appear plausible at the category or language level.

\begin{figure}[t]

Open3DSG (source)~\cite{} predicts \texttt{desk higher than ceiling} at rank 6, although the elevation view places the desk below the ceiling. By estimating predicate--geometry compatibility and re-ranking candidates within relation families, RelCompat3D demotes the inconsistent relation to rank 425, outside the Top-50.}
    \label{fig:teaser}

We study a failure mode in which relation predictors rank plausible labels that are inconsistent with the measured geometry of the ordered subject--object pair \cite{nguyen2026relwitness,neau2026visual}. A relation can be plausible for an object-category pair while contradicting measured distance, projected overlap, or vertical arrangement. This mismatch becomes consequential as 3D scene graphs become interfaces for open-vocabulary applications and embodied systems \cite{koch2024open3dsg,hou2025fross,zhang2025open,wang2025open,saxena2025zing,fei2026open,madhavaram2026vizor}. Figure~\ref{fig:teaser} shows this failure.

The failure is not simply that existing 3D scene graph predictors ignore geometry \cite{wald2020learning}. Prior work already uses edge features, point cloud structure, spatial knowledge, multimodal semantics, and geometric fusion \cite{zhang2021exploiting,feng20233d,wang2023vl,koch2024sgrec3d,chen2024clip}. The gap is more specific. Even when a relation predictor already uses geometry, its source relation score does not necessarily estimate whether the same subject--object pair satisfies the predicate in 3D. This makes the problem a reliability issue, not only a 3DSSG implementation detail: language-based and embodied systems can inherit a high-scoring symbolic relation that contradicts the reconstructed scene evidence. This observation motivates separating predicate semantics $T$, predicate-independent geometry measurements of the ordered pair $G$, and the predictor score $Z$.

We propose RelCompat3D, which preserves each candidate's ordered subject--object identity and learns predicate--geometry compatibility from $T$ and $G$ without using $Z$ or predictor identity. We formulate this separation with family-specific linear heads and a compact shared nonlinear estimator. Both estimators are trained with linked positive--counterfactual pairs so that geometry-consistent candidates outrank their incompatible counterparts. We then average compatibility over known relation-preserving transformations, including endpoint symmetry for proximity and joint endpoint swap with inverse-predicate transformation for vertical-order. These choices address distinct failure modes. Excluding $Z$ prevents direct copying of the predictor score, preserving ordered-pair identity prevents geometry from another object pair from being substituted for the candidate evidence, and transformation averaging assigns equal compatibility to equivalent endpoint/predicate representations.

The predictor score is used only during re-ranking. Within proximity and vertical relations, RelCompat3D combines it with compatibility and changes the order within each relation family. It preserves the sequence of relation-family labels in the source ranking and the source order of support/contact candidates. Matched fusion baselines and ablations test the effects of excluding the source relation score, preserving ordered subject--object pair identity, and enforcing transformation consistency.

We evaluate fixed predictions from Open3DSG, VL-SAT, and a released SceneGraphFusion benchmark model (SGFN) on the official 3DSSG validation split \cite{wang2023vl,koch2024open3dsg,wu2021scenegraphfusion}. These predictors provide complementary open-vocabulary and closed-set relation predictions. We jointly report Recall@$K$ with exact predicate matching and Violation@$K$ computed by a rule-based geometry verifier on a shared 3DSSG. A separate point- and mesh-based audit evaluates the same rankings under an alternative geometric measure. Across all reported $K$ values, both variants improve the Recall--Violation point-estimate trade-off over the source ranking, with the largest changes on Open3DSG.

In summary, our contributions are threefold:
\begin{enumerate}
    \item We define and measure a mismatch between relation scores and instance-level geometric compatibility that exact-match Recall alone does not capture, using identity-preserving evaluation and joint Recall@$K$--Violation@$K$ reporting.
    \item We learn predicate--geometry compatibility from the corresponding ordered subject--object pair without using the predictor score, and enforce invariance under applicable relation-preserving endpoint and predicate transformations.
    \item We introduce a constrained family-aware re-ranking rule and characterize its predictor- and relation-family-dependent behavior across three fixed predictors.
\end{enumerate}

\section{Related Work}
\subsection{3D Scene Graph Prediction}
3D scene graphs organize reconstructed environments as object nodes connected by semantic and spatial relation edges \cite{armeni20193d}.
3RScan provides repeated indoor reconstructions, and 3DSSG adds object-relation annotations and a relation-prediction benchmark \cite{wald2019rio,wald2020learning}. Incremental and online systems study persistent graph construction from RGB-D streams and spatial perception pipelines \cite{wu2021scenegraphfusion,hughes2022hydra}. Recent predictors improve closed-set predicates using edge reasoning, point-cloud features, multimodal cues, spatial knowledge, self-supervised pretraining, object-centric features, and edge-centric representations \cite{zhang2021exploiting,feng20233d,wang2023vl,koch2024sgrec3d,heo2026object,ma2026edge}. These methods and RelCompat3D both use reconstructed scene evidence, but they optimize relation generation, whereas RelCompat3D re-ranks fixed relation candidates after prediction.

Open-vocabulary 3D perception provides queryable object and region features \cite{peng2023openscene,takmaz2023openmask3d}, and graph systems connect features to compact scene representations for querying, planning, navigation, online mapping, and language interaction \cite{gu2024conceptgraphs,werby2024hierarchical,maggio2024clio}. Recent 3D scene graph methods extend this direction to open-vocabulary objects, open-set relations, vision-language model (VLM) features, online graph generation, and functional relations \cite{koch2024open3dsg,chen2024clip,hou2025fross,zhang2025open,wang2025open}. These methods broaden the candidate vocabulary and downstream uses. RelCompat3D keeps each predictor fixed and tests whether its selected predicate is compatible with the reconstructed geometry of the corresponding ordered subject--object pair.

\subsection{Geometry-aware Relation Evidence}
3D relation prediction and graph reuse already rely on edge features, metric distance, topology, support/contact patterns, and semantic-geometric fusion \cite{zhang2021exploiting,feng20233d,xie2024sg,huang2025fireplace,shao2025great,sarkar2023sgaligner}. Scene graph alignment methods further show that graph structure and geometric consistency matter when predicted graphs are reused for matching, alignment, and downstream geometric tasks \cite{sarkar2023sgaligner, xie2024sg}. A recent preprint, RelWitness, learns open-vocabulary relations from visual-geometric witnesses under incomplete relation supervision \cite{nguyen2026relwitness}. These approaches and RelCompat3D share the goal of grounding semantic relations in geometric evidence. RelCompat3D differs by excluding predictor identity and score from compatibility and applying the resulting signal to fixed candidates within each relation family.

Several systems incorporate geometry or transformation structure directly into relation generation. GEODE jointly denoises object geometry and relation predicates inside an open-vocabulary graph generator \cite{feng2026geode}. RelGraphOV uses relation-aware graph construction and geometric pruning to improve open-vocabulary 3D scene representations \cite{chen2026beyond}. Transformation-Aware Decoupling modifies the relation generator to improve viewpoint robustness \cite{sun2026not}. For fixed 2D scene graph generation predictions, Neau et al. mine spatial, functional, and relational constraints and report a Constraint Violation Rate after declarative refinement \cite{neau2026visual}. These methods and RelCompat3D all use structured relation evidence, but RelCompat3D estimates continuous compatibility from the reconstructed ordered subject--object pair and enforces applicable endpoint/predicate transformations before joint Recall@K--Violation@K evaluation.

\subsection{Reliability Evaluation and Calibration}
Confidence calibration asks whether model scores reflect empirical accuracy. Neural network confidence scores often diverge from empirical accuracy, and temperature scaling corrects this divergence without changing the predicted class order \cite{guo2017calibration}. Deep ensembles estimate predictive uncertainty, while evaluations under distribution shift test whether that uncertainty remains reliable \cite{lakshminarayanan2017simple,ovadia2019can}. Selective prediction instead trades conditional risk for coverage \cite{geifman2017selective}. Scene-graph work models semantic ambiguity, calibrates long-tailed predictions, and constructs conformal prediction sets \cite{yang2021probabilistic,zhu2024calibration,nag2025conformal}. In 3D, SCR-SSG refines relation scores from masks, neighboring relations, and statistical priors, while PUF propagates uncertainty during online fusion \cite{yeo2025statistical,yang2026puf}. These methods and RelCompat3D both address reliability beyond task accuracy, but RelCompat3D measures predicate-geometry compatibility rather than calibrated correctness, predictive uncertainty, or absentation decisions.

Recall@K measures retrieval rank rather than compatibility with reconstructed ordered pair geometry. RelCompat3D therefore reports exact-label Recall@K with rule-based Violation@K and uses compatibility for within-family re-ranking. This joint evaluation complements conventional retrieval and calibration analyses without offering a probability guarantee for either metric.

\section{Method}

RelCompat3D re-ranks fixed relation predictions rather than replacing a 3D scene graph generator. It preserves candidate identity, estimates predicate-geometry compatibility without the predictor score, and combines the two only during re-ranking. Figure~\ref{fig:overall_framework} presents an overview of RelCompat3D.

\subsection{Problem Formulation}
Let a relation predictor produce a set of relation candidates for a 3D scene. Each candidate is written as $r_i=(\mathrm{scan}_i,\mathrm{context}_i,s_i,o_i,p_i,a_i,Z_i)$,
where $s_i$ and $o_i$ are ordered subject and object instance identifiers, $p_i$ is the predicate label, $a_i$ is the mapped relation family, and $Z_i$ is the relation score produced by the predictor. We use sigmoid relation scores for VL-SAT/SGFN and cosine similarity between normalized text embeddings for Open3DSG \cite{wang2023vl,wu2021scenegraphfusion,koch2024open3dsg}, without predictor-specific normalization or refitting. Candidates are ranked separately for each predictor, so existing scores are never compared across predictors. A context is a scene subgraph over which top-K selection is performed independently. We distinguish the ordered-pair identity $k^{\rm pair}_i = (\mathrm{scan}_i, \mathrm{context}_i, s_i, o_i)$ from the exact relation-candidate identity $k^{\rm rel}_i = (\mathrm{scan}_i, \mathrm{context}_i, s_i, p_i, o_i)$ used for evaluation. The ordered subject--object pair identity is retained when associating each prediction with geometry and ground truth. We represent predicate semantics as $T_i=p_i$. The family label $a_i$ always selects the transformation set and re-ranking relation families. It also selects the head and training-split normalization statistics for the linear estimator, whereas the shared nonlinear estimator encodes it as a semantic indicator. We then associate predicate-independent geometric measurements of the ordered pair $G_i=G(\mathrm{scan}_i,\mathrm{context}_i,s_i,o_i)$.

The reported relation families are
$\mathcal{A}_{\rm eval}=\{\mathrm{support/contact},\ \mathrm{proximity},\ \mathrm{vertical\ order}\}$,
whose consistency can be evaluated from reconstructed ordered pair geometry. Candidates outside these families are excluded from the reported Recall and Violation evaluation. The re-ranking relation families are narrower: $\mathcal A_{\rm rank}=\{\mathrm{proximity},\mathrm{vertical\ order}\}$, for which the defined endpoint/predicate transformations are available. Support/contact is evaluated but kept in source order because this family requires richer local contact and pose evidence, and no single endpoint transformation preserves the semantics for every predicate in the family.

For estimator $q\in\{\mathrm{lin},\mathrm{mlp}\}$, our objective is to estimate a bounded compatibility score
\begin{equation}
C_i^q=\sigma\!\left(f_q(T_i,a_i,G_i)\right)\in[0,1],
\end{equation}
then average over the valid family-specific endpoint/predicate transformations to obtain the transformation-consistent score $C_i^{\mathrm{tr},q}$. The predictor score is introduced only in the within-family ranking score defined below. $C_i^q$ is a compatibility score used for ranking, not a posterior probability of geometric validity. Training-split ground truth provides positives. Proximity negatives use distant, non-overlapping same-context pairs. Vertical-order negatives retain the ordered pair and replace the ground-truth predicate with its inverse. Support/contact negatives replace one endpoint under separation margins. Separately, relation-preserving augmentation swaps proximity endpoints without changing the predicate and jointly swaps vertical endpoints and the inverse predicate. Evaluation rows, predictor scores, and verifier-status labels are not used to construct training examples.

\subsection{Relation-Consistent Compatibility}
\label{sec:Compatibility}
For each candidate relation $r_i$, the associated geometry vector $G_i$ contains OBB-derived 3D/XY distances, relative height, projected overlap, and vertical-gap features. Point-level contact evidence is used only by the support/contact verifier, not by the compatibility model. Let $\operatorname{std}_{\rm tr}$ standardize each numeric feature with training-split statistics and replace a missing value by the corresponding training mean. We evaluate two compact compatibility estimators under the same input separation, training targets, loss, and transformation averaging.

\subsubsection{Linear Estimator}
The feature map for RelCompat3D-Linear is
\begin{equation}
\begin{aligned}
\Phi_{\rm lin}(T_i,G_i)&=[1;\phi_T(T_i);\operatorname{std}_{\rm tr}(G_i);
\operatorname{std}_{\rm tr}(\phi_{\times}(T_i,G_i))],\\
\phi_{\times}(T_i,G_i)&=
[d(p_i)\Delta z_i,\ d(p_i)\Delta z_i^{\rm norm}].
\end{aligned}
\end{equation}
Here $\phi_T$ contains predicate indicators, and $d(p_i)$ is $1$ for \texttt{higher than}, $-1$ for \texttt{lower than}, and $0$ otherwise. The family label $a_i$ selects the linear head and training-split normalization statistics but is not included as a constant input: $f_{\rm lin}(T_i,a_i,G_i)=w_{a_i}^\top\Phi_{\rm lin}(T_i,G_i)$.

\subsubsection{Nonlinear Estimator}
RelCompat3D-MLP uses one shared two-hidden-unit ReLU network. Its input $\Psi_i$ contains family and predicate indicators, the same underlying geometric measurements, the two signed-height interactions above, and the sum of the two directional overlap ratios. With a predicate-linear skip connection, its logit is
\begin{equation}
\begin{aligned}
h_i&=\operatorname{ReLU}(W\Psi_i+b),\\
f_{\rm mlp}(T_i,a_i,G_i)&=v^\top h_i+b_o+
\beta^\top\phi_T(T_i).
\end{aligned}
\end{equation}
The nonlinear estimator is shared across families, so its family indicator is not a constant feature. Both estimators exclude the predictor score, rank, predictor identity, and object-class features.

For proximity, $\tau$ swaps the ordered endpoints and leaves \texttt{close by} unchanged. For vertical order, $\tau$ swaps the endpoints and maps \texttt{higher than} $\leftrightarrow$ \texttt{lower than}. Transformation averaging therefore outputs
$C^{\rm tr,q}_{\rm close}(s,o)=C^{\rm tr,q}_{\rm close}(o,s)$ and
$C^{\rm tr,q}_{\rm higher}(s,o)=C^{\rm tr,q}_{\rm lower}(o,s)$.

Training combines transformation-consistent augmentation with a linked positive-counterfactual ranking loss. The augmentation preserves the predicate when proximity endpoints are swapped, whereas vertical order swaps endpoints and applies the inverse predicate. In addition, for every linked positive--counterfactual pair $(i^+,i^-)\in\mathcal P$, the logits $\ell_i^q=f_q(T_i,a_i,G_i)$ receive a fixed margin penalty:
\begin{equation}
\begin{aligned}
\mathcal L_q={}&\mathcal L_{\rm BCE}
+0.25\,\mathbb E_{\mathcal P}\!
 \left[\log\!\left(1+e^{1-(\ell^q_{i^+}-\ell^q_{i^-})}\right)\right]\\
&+10^{-4}\mathcal R(\theta_q).
\end{aligned}
\end{equation}
Here $\mathcal L_{\rm BCE}$ is binary cross-entropy over positive and counterfactual examples. The second term is a softplus margin-ranking loss with margin $m=1$ and weight 0.25. The pairwise weight and the $\ell_2$ coefficient $10^{-4}$ are shared across estimators and predictors without predictor-specific search, and $\mathcal R$ penalizes non-bias weights.
Both estimators are fitted exclusively on the training split.

Finally, let $H_{a_i}$ denote the finite transformation group for family $a_i$, and define the transformation orbit $\mathcal O_i=\{g(T_i,G_i):g\in H_{a_i}\}$. We average the learned score over this set to obtain the transformation-consistent compatibility:
\begin{equation}
C_i^{\rm tr,q}=\frac{1}{|\mathcal O_i|}
\sum_{(T',G')\in\mathcal O_i} \sigma\!\left(f_q(T',a_i,G')\right).
\label{eq:algebra-projection}
\end{equation}
Group averaging makes proximity symmetry and invariance under joint endpoint swap and inverse-predicate transformation exact at inference. It does not use the predictor score, while the pairwise objective still orders each linked positive above its counterfactual.

\subsection{Family-Aware Re-ranking}
For each compatibility estimator $q$, define the within-family ranking score
\begin{equation}
u_i^q=\begin{cases}
Z_iC_i^{\rm tr,q}, & a_i\in\mathcal A_{\rm rank},\\
Z_i, & a_i=\mathrm{support/contact}.
\end{cases}
\end{equation}
For positive factors in the families with defined transformations, $\log u_i^q=\log Z_i+\log C_i^{\rm tr,q}$, so compatibility contributes an additive log-score term without a fitted fusion parameter.

Let $\pi^Z=(e_1,\ldots,e_n)$ denote the source ranking and $a_j$ the relation family at position $j$. For each $a\in\mathcal A_{\rm rank}$, let $\pi_a^q$ contain that family's candidates sorted by $u_i^q$, with ties resolved deterministically by exact relation-candidate identity. For support/contact, $\pi_a^q$ is defined directly as the corresponding subsequence of $\pi^Z$ for both estimators. At position $j$, the rule selects the next unused candidate from the corresponding family list, exactly preserving the source family-label sequence. Because the support/contact list retains the source order, its selected subsequence and family-specific Recall and Violation remain unchanged at every $K$. For each prefix, the rule also selects the highest-scoring candidates within each re-ranked family and maximizes their sum of ranking scores subject to the preserved family counts and support/contact subsequence.

RelCompat3D-Linear and RelCompat3D-MLP use different compatibility parametrizations: family-specific linear heads and a shared nonlinear estimator, respectively. Rank-fusion baselines use the same ranking procedure with alternative score combinations. Additional controls test the role of family conditioning, the predictor score, pair identity, geometry, and the defined transformations.

\section{Experiments}
\subsection{Experimental Setup}
\subsubsection{Datasets and Evaluation.}
Predictions come from Open3DSG, VL-SAT, and SGFN \cite{wang2023vl,koch2024open3dsg,wu2021scenegraphfusion}. We evaluate all three on the 3DSSG/3RScan target \cite{wald2019rio,wald2020learning}, restricted to relations whose consistency can be re-ranked from reconstructed ordered-pair geometry. All evaluations use the same scope: 157 scans, 548 relation contexts, and 3,972 exact-match ground-truth relations from support/contact, proximity, and relative vertical families. Ground-truth relations are used only when computing Recall@K, never to filter or rank candidate relations.

\subsubsection{Baselines and Training.}
We evaluate the two compatibility estimators defined in Section~\ref{sec:Compatibility} with identical training rows, constructed targets, split, objective, and family-aware ranking procedure. Their fitted parameters are applied to all three predictors without predictor-specific refitting. Matched rank-average fusion (RankAvg) and reciprocal rank fusion (RRF) combine predictor and linear-compatibility ranks \cite{10.1145/1571941.1572114}. Product (all families) additionally applies the linear support/contact head, and a pooled linear model tests whether family-specific fitting is necessary. Controls perturb the predicate, pair identity, geometric measurements of the ordered pair, endpoint order, predictor score, or distance measurements. We apply the principal controls to both proposed estimators.
Normalization, imputation, and model parameters use only 1,061 training scans; model design and the applicable relation families were selected on the 117-scan development split. The 157-scan evaluation split is never used for fitting. All comparisons across predictors use this shared target.

\subsubsection{Metrics.}
Let $L_K(c)$ be the selected top-$K$ candidates in context $c$ and $Y_c$ its ground-truth relations. Both sets use exact relation identity $(s_i,p_i,o_i)$ within $c$; family mapping is used only for re-ranking and never for label matching. We report
\begin{equation}
\mathrm{Recall@K}=\frac{\sum_c |L_K(c)\cap Y_c|}{\sum_c |Y_c|}.
\end{equation}
Let $D_K\subseteq\bigcup_c L_K(c)$ contain selected candidates for which the rule-based geometry verifier returns satisfied, uncertain, or violated, and let $N_s,N_u,N_v$ denote their respective counts. The primary verifier-derived metric is
\begin{equation}
\mathrm{Violation@K}=\frac{N_v}{N_s+N_u+N_v}.
\end{equation}
Thus uncertain candidates enter the denominator but not the numerator. We also report uncertainty rate $N_u/|D_K|$, decidable-only violation $N_v/(N_s+N_v)$, status coverage $|D_K|/\sum_c|L_K(c)|$, and decidable coverage $(N_s+N_v)/|D_K|$; a variant counts uncertain candidates as violations. We report Recall@K and Violation@K metrics over $K \in \{5, 10, 20, 50, 100\}$. Paired 95\% confidence intervals use 1,000 bootstrap resamples of the 157 scans, keeping all contexts from each scan together and using the same resamples across conditions. Within-family results and family-specific metrics within the selected top-K predictions show whether aggregate changes are driven by relation-family composition.

\subsection{Results}
\subsubsection{Recall--Violation Results}
Table~\ref{tab:main-results} and Figure~\ref{fig:tradeoff} show that the family-aware re-ranking yields a better $K=50$ point estimate Recall-Violation trade-off for all three predictors. For both compatibility estimators, the paired scan-resampling intervals are strictly positive for Recall and negative for Violation on Open3DSG and SGFN. On VL-SAT, whose Source Recall is already high, the Recall intervals contain zero while the Violation intervals remain negative, supporting lower verifier-derived Violation without a detectable Recall loss. Open3DSG exposes the mismatch most strongly: Source baseline ranks geometrically inconsistent relation candidates near the top, whereas both RelCompat3D variants raise Recall and lower Violation without applying a hard filter. Across $K\in\{5,10,20,50,100\}$, no RelCompat3D Recall point estimate is lower than its Source baseline, and the Violation point estimate decreases for every predictor. SGFN is tied at $K=$ and changes only marginally at $K=10$, while Open3DSG shows the largest gains across the reported ranges.

No single ranking rule dominates across all predictors and reported $K$ values. At $K=50$, RelCompat3D-MLP raises Open3DSG Recall more than RelCompat3D-Linear (46.70\% versus 44.18\%) but also has higher Violation (4.13\% versus 3.42\%); the two variants are nearly tied on VL-SAT and SGFN. RankAvg and RRF attain competitive Violation in some reported $K$ values but show larger low-$K$ Recall losses on VL-SAT and SGFN. Product (all families) can raise aggregate Recall and lower aggregate Violation, but it changes support/contact selections and can mask a regression in that family.
Both proposed variants, RankAvg, and RRF use the same family-aware ranking procedure and therefore preserve the source relation-family sequence.

\subsubsection{Ablations and Controls}
Table~\ref{tab:ablations} shows structural controls for RelCompat3D-Linear and includes the RelCompat3D-MLP operating point at $K=50$ and $K=100$. Both are proposed compatibility estimators; the corresponding MLP controls are reported in the supplement. For the Linear head, wrong-pair and shuffled geometry reduce Recall and increase Violation for every predictor at both $K$ values. The results show that the compatibility estimate depends on the corresponding ordered subject--object pair rather than on the marginal distribution of geometry measurements. A wrong predicate and an endpoint swap that keeps the predicate fixed produce the largest Violation increases. Their nearly identical aggregate values arise because both reverse the signed interpretation of vertical-order geometry.

For the Linear head, distance-only ordering raises Open3DSG Recall but substantially increases its Violation, while degrading both metrics on VL-SAT and SGFN. Compatibility-only ordering preserves or lowers Violation but loses Recall on VL-SAT and SGFN, showing that compatibility does not replace the source relation score. RelCompat3D-MLP reaches a different Recall--Violation operating point under the same family-aware ranking procedure.

\subsubsection{Point- and Mesh-Based Consistency Audit}
The compatibility estimators and primary verifier share some OBB-derived measurements. We therefore remeasure proximity and vertical violations directly from reconstructed instance geometry using two representations. One estimate uses robust point-cloud vertex distances and heights and the other uses area-weighted samples from reconstructed mesh triangles. Thresholds are fixed from training-split positive relations. Both estimates exclude OBB measurements, predictor identity, the source relation score, learned compatibility, and primary verifier status labels.

\section{Discussion and Limitations}

All three predictors are evaluated on the same 3DSSG target~\cite{wald2020learning}. The results therefore characterize behavior across predictors on shared data rather than dataset-level generalization. The supplementary ReplicaSSG evaluation using FROSS predictions~\cite{hou2025fross} shows that performance changes under ontology and geometry shifts. RelCompat3D assumes known object instances and reconstructed geometry for each ordered subject--object pair. Correcting support/contact errors, handling relations that require an explicit reference frame, and generating complete scene graphs remain outside scope.

The point- and mesh-based audit still uses the same reconstructed instance geometry and relation ontology, so it does not provide an independent reference for geometric validity. Broader claims require independently defined reference labels, richer contact and pose evidence, and evaluation on additional datasets.

\section{Conclusion}
RelCompat3D learns predicate--geometry compatibility separately from the source relation score, enforces relation-preserving transformations, and re-ranks proximity and vertical candidates within their families. Across three predictors on a shared 3DSSG, both variants yield lower verifier-derived Violation point estimates while preserving or improving Recall point estimates at every reported $K$.
