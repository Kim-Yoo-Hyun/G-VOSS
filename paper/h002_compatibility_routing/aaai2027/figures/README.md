# AAAI 2027 Figure Assets

Future figure assets for the H002 AAAI-27 source belong here.

AAAI-27 constraints to preserve:

- use high-resolution figures suitable for print
- avoid low-resolution screenshots or GIF files
- do not use figure assets that de-anonymize the authors
- do not use external links or embedded PDF bookmarks

Current generated vector assets:

- `comparison_tradeoff_ci.pdf`: main-paper Recall/Violation tradeoff with CI.
- `qualitative_reranking_rows.pdf`: actual validation-row examples for the supplement.
- `failure_routes.pdf`: front/behind and support/contact failure visualization.

They are generated by the Docker service
`h002-paper-strengthening-assets`; do not edit the PDFs manually.
