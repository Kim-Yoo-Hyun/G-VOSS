\section{Non-Submission Codex Blind Proxy Audit}
\label{sec:codex-proxy}

This section is analysis-only and is excluded from the submission manuscript.
It reports non-human proxy evidence, not human annotation. Two separately
locked Codex passes reviewed the same 488 relation-pair items using only the
public relation text and ordered-pair geometry evidence. Neither pass accessed
source identity, scores, ranks, verifier outputs, ground-truth membership, or
the other pass before lock. Because both passes use the same model family, they
measure automatic-judge stability rather than independent inter-rater validity.

The passes agree on 438/488 items (89.75\%; four-class $\kappa=0.845$). Among
334 items that both resolve as physically valid or invalid, there is no direct
valid/invalid polarity flip. For a conservative proxy estimate, we retain only
exact pass agreements and map every disagreement to ambiguous; ambiguous and
unobservable items are excluded from the binary denominator and reported
through resolution coverage. Table~\ref{tab:codex-proxy} gives design-weighted
estimates under the frozen audit sample.

The proxy direction agrees with the verifier-based Open3DSG conclusion and is
smaller but consistent on VL-SAT. The absolute values differ substantially from
verifier V, especially on VL-SAT, and binary resolution coverage ranges from
0.568 to 0.847. This discrepancy is useful diagnostic evidence: it prevents the
Codex proxy from being treated as a replacement ground truth and leaves the
construct-validity concern open until an independent human reference is
collected and adjudicated.
