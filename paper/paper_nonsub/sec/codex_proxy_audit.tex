\section{Non-Submission Codex Blind Proxy Audit}
\label{sec:codex-proxy}

This section is analysis-only and is excluded from the submission manuscript.
It reports non-human proxy evidence, not human annotation. Two separately
locked Codex passes reviewed the same 488 relation-pair items using only the
public relation text and ordered-pair geometry evidence. Neither pass accessed
source identity, scores, ranks, verifier outputs, ground-truth membership, or
the other pass before lock. Because both passes use the same model family, they
measure automatic-judge stability rather than independent inter-rater validity.

The passes agree on 438/488 items (89.75\%; four-class $\kappa=0.845$). Among
334 items that both resolve as physically valid or invalid, there is no direct
valid/invalid polarity flip. We then visually adjudicated all 154 mandatory
rows: all 50 label disagreements and every low-confidence, ambiguous, or
unobservable decision. This changed 22 low-confidence agreed-ambiguous labels
to invalid. The resulting proxy reference contains 178 valid, 212 invalid, 95
ambiguous, and three unobservable items. Ambiguous and unobservable items are
excluded from the binary denominator and reported through resolution coverage.
Table~\ref{tab:codex-proxy} gives design-weighted estimates under the frozen
audit sample. The sampled ranking sidecar predates the relation-algebra model,
so the product rows test the historical family-conditioned product rather than
the current projected compatibility score.

At $K=100$, proxy V changes by $-0.0711$ on VL-SAT (95\% scan-bootstrap CI
$[-0.1219,-0.0252]$) and $-0.2975$ on Open3DSG
($[-0.3961,-0.1951]$). Thus the proxy direction agrees with the historical
verifier-based conclusion on both sources.

We separately reveal the verifier result only after the proxy reference is
locked. Of 390 binary proxy labels, the verifier is decisive on 282. Its
design-weighted agreement with the proxy is 0.731 (95\% scan-bootstrap CI
$[0.613,0.858]$), with weighted $\kappa=0.467$. Treating the proxy as the
reference, verifier-invalid precision is 1.000 but recall is only 0.471. The
agreement is strongest for vertical order ($\kappa=0.814$) and substantially
weaker for proximity (0.042) and support/contact (0.203); verifier decidability
for support/contact is only 0.298. This pattern is inconsistent with a
universally self-confirming verifier: it is conservative relative to the
visual proxy and misses many proxy-invalid cases. It nevertheless remains an
LLM-derived reference. External reviewers A, B, and C subsequently checked all
488 completed rows and confirmed every label without revision at
\texttt{2026-07-14T22:49:11+09:00}. The final artifact is therefore
reviewer-verified LLM annotation. Because reviewers saw the completed Codex
reference rather than independently labeling blank sheets, it is not three
independent first-pass human annotations and does not establish Human V@$K$.
