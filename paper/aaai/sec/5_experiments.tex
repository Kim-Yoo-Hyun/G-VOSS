\section{Experimental Setup}

This section fixes the experimental scope before reporting results, because
H001's claim depends on denominator transparency as much as on metric values.
We use two source roles. Open3DSG is the main open-vocabulary relation-source
case study, rather than a broad generation benchmark, because it is closest to
the target setting of queryable objects and open-set relationships. VL-SAT is a
controlled reproduced closed-set anchor that helps test whether the same
reliability mechanism appears under a cleaner source contract. The families and
denominator are fixed before source-result
reporting, so the evaluation tests a predeclared physically checkable slice
rather than a post-hoc set of favorable predicates. The paper-facing H001 scope
is the full official 3DSSG-subset validation split: 157 scans, 548 contexts,
36,808 directed pairs, 957,008 VL-SAT prediction rows, 11,254 ground-truth rows,
and 3,972 in-scope GT relation instances across the measured
geometry-checkable families. Table~\ref{tab:scope} records the denominator and
the source outputs used by the main source-result table
(Table~\ref{tab:source-results}).

The Open3DSG result is reported as a Docker-reproduced source-output reliability
case study, not as an official Open3DSG leaderboard reproduction. The selected
full-validation checkpoint is the official non-averaged BLIP route
\texttt{epoch=13-step=13104.ckpt}, chosen by train-dev validation loss before
H001 held-out inspection. The runtime uses a filtered preprocessed-ready train
split of 3,744/3,852 subgraphs and a train-dev validation split of 156/160
subgraphs. The primary Open3DSG full-validation branch covers 548/548 contexts
by using a recovery policy: \texttt{OPEN3DSG\_MIN\_VISIBLE\_OBJECTS=2} and
relaxed view regeneration for two scans. The original 533/548 covered branch is
retained as an unmodified-source-route sensitivity check. These caveats remain
visible because Open3DSG is the main open-vocabulary relation-source case study.
The claim is therefore within-source reliability under a fixed reproduced source
contract, not a broad generation claim.

Table~\ref{tab:claim-boundary} fixes how each source may be used. This is part
of the experimental design: a result can support the paper only if it passes
the same row contract, geometry join, denominator, metric, and caveat reporting
discipline.

All paper-body experiment results are generated through Docker under
\texttt{experiments/H001\_geom\_reliability/}. The paper reports exact-label
\rAt{50} and \rAt{100}, \vAt{50} and \vAt{100}, Open3DSG and VL-SAT source
results, GT-positive/counterfactual verifier evaluation, nontriviality
controls, structured audit and reduced visual sanity checks, source-specific
claim boundaries, and qualitative failure analysis. Host-only outputs are not
promoted to paper evidence.
