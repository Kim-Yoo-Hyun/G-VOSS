\section{Experiments}

\subsection{Experimental Setup}

\paragraph{Data and splits.}
Predictions come from Open3DSG, VL-SAT, and the released SceneGraphFusion
(SGFN) model \texttt{SGFN\_full\_l160}
\cite{koch2024open3dsg,wang2023vlsat,wu2021scenegraphfusion}. We evaluate all
three on one 3DSSG/3RScan target~\cite{wald2019rio,wald2020learning3dssg}, restricted to
relations whose consistency can be assessed from reconstructed ordered-pair
geometry. All
evaluations use the same scope: 157 scans, 548
relation contexts, and 3,972 exact-match
ground-truth relations from support/contact, proximity, and vertical-order
families. Ground-truth membership is used only when
computing Recall@$K$, never to filter or rank candidate relations.

Open3DSG uses the publicly released model and preprocessing pipeline. Every
evaluation context is retained, with unavailable candidate lists treated as
empty; coverage and denominator sensitivities are in the supplement.

\paragraph{Baselines and training.}
We evaluate the two compatibility estimators defined in Method with identical
training rows, constructed targets, split, objective, and family-aware ranking
procedure. Their fitted parameters are applied to all three predictors without
predictor-specific refitting. Matched rank-average fusion (RankAvg) and reciprocal rank fusion
(RRF)~\cite{cormack2009rrf} combine predictor and linear-compatibility ranks.
Product (all families) additionally applies the linear support/contact head,
and a pooled linear model tests whether family-specific fitting is necessary.
Controls perturb the predicate, pair identity,
geometric measurements of the ordered pair, endpoint order, predictor score, or distance
measurements; we apply the principal controls to both proposed estimators, with
exact transformations in the supplement. Normalization, imputation, and model
parameters use only 1,061
training scans; model design and the applicable relation families were selected
on the 117-scan development split.
The 157-scan evaluation split is never used for fitting. All comparisons across
predictors concern this shared target.

\paragraph{Metrics and uncertainty.}
Let $L_K(c)$ be the selected top-$K$ candidates in context $c$ and $Y_c$ its
ground-truth relations. Both sets use exact relation identity
$(s_i,p_i,o_i)$ within $c$; family mapping is used only for re-ranking and never
for label matching. We report
\begin{equation}
\mathrm{Recall@K}=\frac{\sum_c |L_K(c)\cap Y_c|}{\sum_c |Y_c|}.
\end{equation}
Let $D_K\subseteq\bigcup_c L_K(c)$ contain selected candidates for which the
rule-based geometry verifier returns satisfied, uncertain, or violated, and
let $N_s,N_u,N_v$ denote their respective counts. The primary verifier-derived
metric is
\begin{equation}
\mathrm{Violation@K}=\frac{N_v}{N_s+N_u+N_v}.
\end{equation}
Thus uncertain candidates enter the denominator but not the numerator. We also
report uncertainty rate $N_u/|D_K|$, decidable-only violation
$N_v/(N_s+N_v)$, status coverage
$|D_K|/\sum_c|L_K(c)|$, and decidable coverage $(N_s+N_v)/|D_K|$; a
pessimistic variant counts uncertain candidates as violations. We report
$K\in\{5,10,20,50,100\}$ and discuss
$K=50$ as an intermediate reported budget. Paired 95\% confidence intervals
use 1,000 bootstrap resamples of the 157 scans, keeping all contexts from each
scan together and using the same resamples across conditions. Within-family results and family-specific
metrics within the selected top-$K$ predictions show whether aggregate changes
are driven by relation-family composition.
