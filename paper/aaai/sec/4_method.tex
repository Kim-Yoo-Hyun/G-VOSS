\section{Method}

\method{} is a framework for 3D scene graph relation predictions. It is
not a replacement relation predictor and not a standalone hand-coded verifier.
The geometric checks define the measurable validity target for families with
observable physical constraints; the method contribution is the
identity-preserving row contract, factor separation, calibrated compatibility,
operating-point analysis, and controls. The design preserves row identity,
joins predicate-independent same-pair geometry, excludes source confidence
from compatibility calibration, and evaluates recall and violation jointly.
Figure~\ref{fig:framework} presents this path to calibrated operating points.

\subsection{Relation-Row Standardization}

Different relation sources expose predictions in different formats. We convert
each source output into a shared row contract:
\begin{equation}
(\mathrm{scan},\mathrm{subgraph},s,o,p,a,\mathrm{score}^{sem},\mathrm{source}).
\end{equation}
This row is the unit of comparison across VL-SAT, Open3DSG, controls, and
future optional sources. The standardized row keeps the semantic score from the
source model but adds the fields needed for identity-preserving geometry joins
and denominator-stable evaluation.

\subsection{Identity-Preserving Geometry Join}

Geometry is joined by $(\mathrm{scan},\mathrm{subgraph},s,o)$, not by category
names or unordered object-pair statistics. This matters because the same
predicate can be plausible for many object categories while being false for a
particular instance pair. The wrong-pair and shuffled-geometry controls
directly test this design choice by breaking or perturbing object-pair identity
while preserving parts of the geometry distribution.

\subsection{Family-Specific Geometry Checks}

\method{} uses relation-family-specific checks for \texttt{support\_contact},
\texttt{proximity}, and \texttt{relative\_vertical}. For support/contact, the
evidence includes point/local contact, vertical support, OBB overlap, and
support subtypes. For proximity, the evidence includes object distance and pair
scale. For relative vertical relations, the evidence includes centroid and
extent ordering along the vertical axis. The verifier returns violated only
when the evidence is strong enough; otherwise ambiguous or weak geometry can be
marked uncertain. We do not apply this protocol to predicates whose correctness
depends primarily on function, social context, affordance, or language
pragmatics, because those predicates do not have a stable geometric validity
test from the available reconstruction alone.

\subsection{Factor-Isolated Calibration and Fusion}

For each row, $T_i$ denotes predicate/family semantics, $G_i$ raw
predicate-independent same-pair geometry, and $Z_i$ source confidence. The
frozen family-conditioned calibrator is
\begin{equation}
\begin{split}
\pgeomfam_i=C_i &={} C_{a_i}(\Phi(T_i,G_i)),\\
                 &={} P(y_i^{cal}=1\mid T_i,G_i),
\end{split}
\end{equation}
Here $\Phi=(\phi_T,\phi_G,\phi_{\times})$; $\phi_{\times}$ contains explicit
predicate-aligned transforms such as signed vertical displacement while raw
$G_i$ remains predicate-independent.
The leakage boundary is
\begin{equation}
Z_i\notin\operatorname{inputs}(C_i).
\end{equation}
Source confidence and identity are absent from calibrator features and enter
only after $C_i$ is fixed. A pooled calibrator with the same boundary is the
\texttt{pooled\_risk} ablation. Both use 2,565 train-dev GT positives and 3,244
high-margin counterfactual negatives, so $y^{cal}$ is constructed rather than
human validity. Family maps, rules, counterfactuals, and calibrators are frozen
from train-dev artifacts without held-out retuning.

We first use geometry validity as a soft risk term. For the calibrated product,
$R^{geom}_i=-\log \pgeomfam_i$ and
\begin{equation}
U_{\lambda}(i)=\log \mathrm{score}^{sem}_i-\lambda R^{geom}_i.
\end{equation}
The reported product fixes $\lambda=1$, giving
\begin{equation}
\mathrm{score}^{\mathrm{product}}_i =
\mathrm{score}^{sem}_i \cdot \pgeomfam_i.
\end{equation}
This preserves the source ranking signal while continuously penalizing
calibrated inconsistency; $\lambda$ is not tuned on held-out source results.

The second soft instantiation removes source-scale assumptions. Within each
subgraph, let $q_i^{sem}$ and $q_i^{geom}$ be descending percentile ranks of
$\mathrm{score}^{sem}_i$ and $\pgeomfam_i$. Rank-average assigns
\begin{equation}
\mathrm{score}^{\mathrm{rank}}_i =
\tfrac{1}{2}(q_i^{sem}+q_i^{geom}).
\end{equation}
The equal weight is parameter-free and fixed before SGFN inference. The product
uses calibrated probability magnitudes; rank-average is scale-robust. We treat
them as two GeoCalib fusion instantiations rather than claiming one formula is
universally optimal. We additionally report
\texttt{probabilistic\_recalibrated} as the pooled calibrated-risk ablation
$\mathrm{score}^{sem}_i \cdot \pgeom_i$, fixed-constant Reciprocal Rank Fusion
as a strong comparison, and \texttt{rule\_verified\_point\_subtype} as a hard
zero-violation diagnostic.

\subsection{Controls}

The control conditions test whether the result can be explained by simpler
signals. The legacy \pgeom{}-only ranking removes $Z_i$ and is therefore
distinct from the pooled calibrated-risk ablation, which still multiplies
source confidence by \pgeom{}. We call it calibrator-only, not true $G$-only,
because the calibrator retains $T_i$ and $T_i\!\times\!G_i$ features.
Distance-only ranking tests whether a generic spatial
heuristic explains the result. Shuffled-geometry and wrong-pair-geometry
controls test whether relation-level object-pair identity is necessary. If
these controls perform worse than the calibrated setting, the result supports
the framework design rather than a generic ``add geometry'' explanation.
