\section{Compatibility Model and Calibration Diagnostics}

GeoCalib fits one logistic model per measured relation family. Numeric features
are standardized by training-only means and standard deviations; missing
numeric values use the corresponding training mean. The input groups are
predicate/family indicators $T$, predicate-independent distances, extents,
overlap, contact, and vertical measurements $G$, and two direction-aligned
vertical interactions $T\!\times\!G$. Source score and source identity are
forbidden. All models use binary cross-entropy, $L_2=10^{-4}$, 800 fixed
gradient steps, and learning rate 0.2.

The factor-isolation audit uses the same train/dev rows and estimator class,
without inspecting source-result metrics. At dev, $T$-only, true raw-$G$-only,
additive $T+G$, and interaction $T\times G$ obtain AUROC
.6124/.8809/.9193/.9822 and Brier .2370/.1363/.1061/.0495. This establishes
that predicate--geometry interaction improves the constructed-target fit; it
does not convert the target into independent physical-validity ground truth.
