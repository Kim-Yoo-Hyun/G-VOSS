\section{Guarantees and Compatibility Diagnostics}

\paragraph{Proof of Proposition 1.}
For any $h\in H_a$,
\(
P_af(hx)=|H_a|^{-1}\sum_{g\in H_a}f(ghx)
\).
Right multiplication by $h$ is a bijection on the finite group, so re-indexing
$g'=gh$ gives $P_af(hx)=P_af(x)$. Thus $P_af$ is constant on each declared
orbit. Averaging an already orbit-constant function leaves it unchanged,
which proves $P_a^2=P_a$. The two-element proximity and vertical actions yield
the identities in the main paper, and the singleton action is the identity.

\paragraph{Proof of Proposition 2.}
At position $j$, the routing algorithm pops from the queue indexed by the
source family $a_j$; hence the output family sequence is exactly
$(a_1,\ldots,a_n)$. A pass-through queue retains source-relative order, so the
first $K$ positions contain exactly the same ordered support/contact
subsequence as the source prefix. For optimality, consider two slots
$p<q$ of the same family. If $u(e_p)<u(e_q)$, exchanging them changes the
weighted objective by
$(\omega_p-\omega_q)(u(e_q)-u(e_p))\geq0$.
Repeatedly removing such inversions gives the descending family queues used by
the route, proving optimality over all family-sequence-preserving
permutations. Ties may yield multiple optima without changing either guarantee.

\paragraph{Counterfactual target construction.}
Measured-family ground-truth rows provide positives. Negatives are generated
within the same scene context and linked to their source positive; no source
score, predictor identity, or validation-split row is used.
Table~\ref{tab:counterfactual-rules} gives the complete construction policy.

At most two negatives are emitted per positive, 200 per context--family, and
three times the number of positives per family. These caps limit repeated easy
negatives; they do not equalize family counts. The export contains 28,977
positives and 37,477 negatives (23,008 proximity, 5,488 vertical, and 37,958
support/contact rows). The explicit overlap above is why verifier-derived V is
reported as a related diagnostic rather than independent physical-validity
ground truth; the held-out-primitive analysis tests, but does not eliminate,
this construct dependence.

\method{} fits one logistic model per measured relation family. Numeric
features use training-only means and standard deviations; missing values use
the corresponding training mean. Inputs are predicate/family indicators $T$,
predicate-independent pair geometry $G$, and explicit $T\!\times\!G$
interactions. Source score, source rank, source identity, and object class are
forbidden. Orbit-consistent augmentation preserves the proximity predicate
under endpoint swap; vertical order swaps endpoints and applies the inverse
predicate. Linked counterfactuals receive the fixed margin loss in the main
paper. Support/contact receives the pairwise loss but no blanket endpoint
transform.

The 60,208 training rows yield 33,961 linked pairs, and algebra augmentation
produces 86,032 optimization rows. We use 800 deterministic full-batch steps at
learning rate 0.2; the three family models contain 22--24 parameters. The
support/contact model is used only in unrestricted-fusion diagnostics, while
the primary family-slot route preserves that family's source ordering.
