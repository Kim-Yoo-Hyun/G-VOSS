\section{Related Work}

\paragraph{3D Scene Graph relation prediction.}
3D Scene Graphs organize indoor scenes as object-relation structures grounded
in 3D space \cite{armeni20193dscenegraph}. The 3RScan/3DSSG setting
established predicate recall for 3D relation prediction
\cite{wald2020learning3dssg}, while incremental and online systems study how
scene graphs can be constructed from RGB-D streams or spatial perception stacks
\cite{wu2021scenegraphfusion,hughes2022hydra}. Recent predictors improve
closed-set predicates using edge reasoning, point-cloud features, multimodal
cues, spatial knowledge, self-supervised pretraining, object-centric features,
and edge-centric relational reasoning
\cite{zhang2021sggpoint,feng2023smka,wang2023vlsat,koch2024sgrec3d,heo2025ocrl3dssg,ma2026leo}.
These methods already use geometry; \method{} instead targets the post-source
reliability gap that a high semantic relation score need not be calibrated to
physical validity for the same object pair.

\paragraph{Open-vocabulary 3D graphs.}
Open-vocabulary 3D perception provides queryable object and region features
\cite{peng2023openscene,takmaz2023openmask3d}; graph systems then connect such
features to compact scene representations for querying, planning, navigation,
online mapping, and language interaction
\cite{gu2024conceptgraphs,werby2024hovsg,maggio2024clio}. Recent 3D scene graph
work extends this line toward open-vocabulary objects, open-set relations, VLM
features, online graph generation, and functional relations
\cite{koch2024open3dsg,chen2024ccl3dsgg,hou2025fross,zhang2025openfungraph,wang2025octreegraph}.
This line raises the reliability requirement: when relation edges are
language-facing scene representations, plausible text labels must still refer
to object pairs that satisfy the corresponding spatial relation.

Other recent systems further connect VLMs, zero-shot graph construction,
graph-mediated LLM reasoning, retrieval augmentation, and hallucination
mitigation
\cite{saxena2025zing3d,madhavaram2026vizor,yu2025openworld3dsg,zemskova2025graphllm,ogunleye2026vcd}.
We cite them as trend and boundary evidence, not direct \method{} baselines.

\paragraph{Geometry-aware relation evidence.}
A broad set of 3D reasoning methods already uses geometry: edge features,
support/contact patterns, affordance geometry, metric distance, topology, and
semantic-geometric fusion
\cite{zhang2021sggpoint,feng2023smka,huang2025fireplace,shao2025great,xie2024sgpgm}.
Scene graph alignment and registration methods further demonstrate that graph
structure and geometric consistency matter when scene graphs are reused for
matching, alignment, and downstream geometric tasks
\cite{sarkar2023sgaligner,xie2024sgpgm}.

RelWitness uses visual-geometric witnesses, calibrated witness quality, and
witness-consistent decoding for open-vocabulary 3D scene graph generation
\cite{nguyen2026relwitness}. Statistical confidence rescoring refines 3D scene
graph predictions from multi-view images using semantic masks, neighboring
relations, and statistical priors \cite{yeo2025scrssg}. \method{} therefore
does not claim novelty from visual-geometric evidence, calibration, or
rescoring alone. It studies a different post-source contract:
identity-preserving geometry joins, recall/violation operating points, and
controls over existing relation-source outputs.

Recent reliability-adjacent systems sharpen this boundary. SGFormer++ uses a
spatial feature adapter inside an incremental predicate predictor
\cite{qi2026sgformerpp}; RelGraphOV prunes geometrically implausible relations
while learning an open-vocabulary scene representation
\cite{chen2026relgraphov}; and PUF performs uncertainty-aware semantic--spatial
fusion for online node association and evidence accumulation
\cite{yang2026puf}. In contrast, \method{} leaves each source model fixed and
audits already-produced relation candidates through a source-excluded,
same-pair compatibility factor. The supplement compares these contracts
directly.

\paragraph{Reliability and calibration.}
Standard \rAt{K} asks whether the correct predicate appears near the top, not
whether the predicted relation is physically valid in the reconstructed scene.
Confidence calibration asks whether model scores reflect empirical correctness
likelihood \cite{guo2017calibration}, and selective prediction makes risk and
coverage explicit \cite{geifman2017selective}. \method{} instantiates this
reliability view for geometry-checkable 3DSSG families by standardizing
prediction rows, joining same-pair 3D evidence, estimating compatibility, and
reporting recall together with violation.
