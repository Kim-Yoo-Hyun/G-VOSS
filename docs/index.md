# Research Documentation Index

Last updated: 2026-07-11 KST

## Purpose

`docs/index.md`는 상태 dashboard가 아니라 문서 색인이다. 이 파일은 "어떤 정보를 어디서
찾아야 하는가"만 안내한다. 최신 상태, 수치, 실행 로그, artifact 목록은 각 owning document가
소유한다.

External convention checked on 2026-06-25 KST:

- MkDocs uses `index.md` as the page rendered to `index.html` for a directory
  entry page: https://www.mkdocs.org/user-guide/writing-your-docs/
- Docusaurus treats `index.md` or `README.md` as a category index document:
  https://docusaurus.io/docs/sidebar/autogenerated
- Sphinx-style documentation uses an index/root page as a table-of-contents
  entry point: https://www.sphinx-doc.org/en/master/usage/restructuredtext/directives.html

따라서 이 repository에서도 `docs/index.md`는 navigation / table-of-contents 역할만 맡는다.
`docs/README.md`는 GitHub folder entry point 역할을 하고, 세부 진행 상태를
복사하지 않는다.

## Update Rule

- Do not store live status, metric tables, row counts, or long artifact lists in this file.
- Add a pointer here only when a durable documentation area is created, renamed, or archived.
- Put current work in `TODO.md`.
- Put workflow rules in the relevant `docs/*.md`.
- Put folder-local status, commands, and artifact details in that folder's `README.md` or report file.
- If a `docs/*.md` file starts accumulating progress logs, split those logs back
  to the nearest owning folder and leave only rule-level decisions or pointers.
