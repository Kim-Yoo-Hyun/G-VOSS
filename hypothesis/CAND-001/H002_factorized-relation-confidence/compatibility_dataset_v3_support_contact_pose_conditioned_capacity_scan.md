## Purpose

This runner checks whether the frozen support/contact target contract is feasible on train-side
rows. It does not create the final dataset and does not train a model.

The target contract is:

```text
same G_e anchor + T_e = lying on
same G_e anchor + T_e = standing on
```

The anchor pose determines which predicate is compatible.
