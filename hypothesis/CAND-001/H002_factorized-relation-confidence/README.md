## Claim Boundary

H002 is a route-aware factorized reliability/reranking framework over existing
relation sources. It does not replace VL-SAT or Open3DSG.

Core score:

```text
T_e = predicate / relation-family semantic content
G_e = predicate-independent geometry evidence
Z_e = source confidence, score, rank
C_e = compatibility(T_e, G_e)
Q_e = observability / evidence quality
S2(e) = normalized_source_score(Z_e) * C_e
p_obs = P(evidence is sufficient to decide | Q_e)
p_rel = P(relation is reliable | observable evidence, Z_e, C_e)
```
