# Open3DSG Avg-BLIP Checkpoint Route

Status: selected_for_next_pilot
Created at: 2026-05-15 16:13 KST

## Reason

The official non-averaged BLIP projector route failed three checkpoint-smoke
attempts with CUDA OOM:

- first pilot: epoch 0 step 1419/3744
- retry with projector chunk size 4: epoch 0 step 235/3744
- retry2 with projector chunk size 1: epoch 0 step 699/3744

No `.ckpt` checkpoint was produced.

## Selected Lower-Memory Route

Use Open3DSG's existing CLI option:

```text
--blip --avg_blip_emb
```

This is compatible with the official dumped BLIP features, whose relation
feature tensors have shape:

```text
[num_edges, 257, 1408]
```

With `--avg_blip_emb`, Open3DSG averages the 257 BLIP patch tokens in the loss
path and skips the train-time BLIP projector. This removes the repeated OOM
site while keeping the official BLIP feature dump and Open3DSG training script.

## Claim Boundary

This route is a reproducible lower-memory Open3DSG variant, not the exact
non-averaged BLIP projector route. If it becomes the selected Open3DSG
second-source checkpoint, the paper table must label it as an averaged-BLIP
Open3DSG reproduction/variant and report the failed non-averaged checkpoint
attempts as a reproducibility limitation.
