# H002 Compatibility Routing Experiments

Last updated: 2026-07-11 KST

Docker-based runtime workspace for the scoped H002 claim.

## Main Experiment

\[
C_e^{\rm raw}=f_C(T_e,G_e),\qquad
S_2(e)=\widetilde Z_e\widetilde C_e.
\]

Raw \(C_e\) excludes source score/rank. Source score is normalized per source
and compatibility per source-family before multiplication. VL-SAT and Open3DSG
predictions are reranked on the official 3DSSG validation split and evaluated
with Recall@K and custom Violation@K.

## Storage Policy

Large source-wide `*.jsonl` selections are intentionally not retained. They can
be regenerated by the materialization and metric services. Compact CSV/JSON
metrics, CI, manifests, and qualitative examples are retained.

`latest/summary.json` or stage reports may retain the `next_todo` that was valid
when that stage was produced. Those fields are immutable provenance, not the
current task queue. Current state is owned by this README and `TODO.md`.

Discarded branches are not current claim inputs:

- learned G_e
- p_obs/p_rel
- repeated support/contact repair variants
- official-test resolution attempts
- paper transition/handoff scaffolds

## Execution

Use `commands.md`. All paper-facing experiment results must be reproduced
through `configs/h002/compose.yaml`. H001 result and experiment mounts are
read-only.

## Claim Boundary

Main validated routes are relative vertical and relative size. Left/right is
caveated. Close by is a geometry-only control. Front/behind and support/contact
are failure/diagnostic routes. No official hidden-test, SOTA, solved
support/contact, learned-G_e, or calibrated p_obs/p_rel claim is allowed.

## Current State

The scoped pipeline and compact outputs are complete. No additional experiment
is automatically open. A broader route, external release, or submission action
requires an explicit decision and a frozen protocol.
